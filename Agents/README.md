# Agents — синхронизация между агентами и людьми

Папка для передачи контекста между агентами (Claude Code и т. п.) и участниками команды.
Читать по порядку:

1. [CONTEXT.md](CONTEXT.md) — что за задача, откуда исходники, где что лежит.
2. [PROGRESS.md](PROGRESS.md) — что уже сделано (с путями к файлам) и что НЕ проверено.
3. [NEXT_STEPS.md](NEXT_STEPS.md) — что делать дальше: сборка, тесты, чек-лист проверки.
4. [DISCREPANCIES.md](DISCREPANCIES.md) — найденные расхождения между описанием команды и реальным кодом.
5. [HANDOFF_LOG.md](HANDOFF_LOG.md) — журнал: каждый, кто работает над проектом, дописывает сюда запись.
6. [reference/TEAM_FORK_CHANGES_ANALYSIS.md](reference/TEAM_FORK_CHANGES_ANALYSIS.md) — исходный документ команды (ТЗ), без изменений.

Правило: закончили сессию — допишите запись в `HANDOFF_LOG.md` и обновите чек-листы в `PROGRESS.md`/`NEXT_STEPS.md`.
